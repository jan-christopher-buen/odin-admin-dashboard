# odin-admin-dashboard

An admin dashboard layout built with CSS Grid and Flexbox for The Odin Project.

**Live preview:** https://jan-christopher-buen.github.io/odin-admin-dashboard/

## About

This page recreates The Odin Project's admin dashboard design: a sidebar with navigation, a header with a search bar and action buttons, and a main area with project cards, announcements, and trending users.

## What I practiced

- Building a full page layout with CSS Grid (`grid-template-columns`, `grid-template-rows`, and `grid-row` spanning)
- Using `fr` units, `auto`, and `repeat()` to size grid tracks
- Nesting Grid and Flexbox: Grid for page sections, Flexbox for items inside them
- Pushing card icons to the bottom with `margin-top: auto`
- Styling a list item differently with `:last-child`
- Using an icon font for all icons

## Built with

- HTML
- CSS (Grid and Flexbox)
